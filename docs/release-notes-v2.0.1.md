# YesBanGDream v2.0.1

本次更新修复协力开演误判和直接启动时的 Profile 读取错误，恢复 MuMu 前台启动行为，并换用新的双角色相框图标。

## ✨ 新功能

- 🖼️ 更新程序、窗口、更新器及 README 图标，统一使用新的双角色相框图片。
- 🎹 同时提供 Legacy / Native 两份 Expert 已验收 Profile：1280×720、DPI 240、游戏 60 FPS、standard 画质、流速 5.0、时序偏移 60 ms。完整包内置，更新只补缺失文件；另附独立校准 ZIP，便于手动导入。
- ⚙️ 新安装默认使用 Legacy、按环境自动选择 Profile；开启 Native 后使用匹配的 Native 文件。已有手动钉选保持不变，切换引擎时请在“演出设置”选择对应 Profile。

## 🐛 修复

- 🛠️ 协力准备页的成员卡片动画曾被误当作正在演奏的音符，提前停止等待并触发断网退出；现在准备／取消按钮仍在时继续等待真实黑场或可信封面。
- 🛠️ 直接启动程序时，GBK / UTF-8 编码差异可能破坏含中文的 Profile 响应；改用标准 Unicode 转义，保留中文内容及原校准文件。
- 🛠️ 撤回 MuMu 已处于游戏前台时的重复唤起和横竖屏稳定等待，避免任务开始、完成时额外切换；正常启动、后台切回及失败恢复继续保留。

## 📦 更新方式

- 🔄 已安装 2.0.0 的用户可使用客户端更新或更新 ZIP，保留配置、Profile、诊断目录和本地谱面。默认 Profile 通过独立种子目录只补缺失文件，不覆盖选择或校准。
- 📥 首次使用下载 `YesBanGDream-v2.0.1-win-x64.zip`，完全解压到新目录，双击 `启动 YesBanGDream.cmd`。
- 📢 更新后展示本次版本说明；完整包、更新包、定制 MFA 源码包和 Expert 校准包均附 SHA256。
