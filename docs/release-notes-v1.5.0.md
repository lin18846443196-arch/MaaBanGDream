# RhythmPilot v1.5.0

基于 MaaBanGDream 的非官方版本，由 lin18846443196-arch 独立维护。
以定制 1.4.3 为基线，迁入上游 1.4.4/1.4.5 的曲库、演出保护、协力和发布流程更新。

## 功能

- 挑战演出自动识别所持点数，选择 8/4/2/1 倍；支持难度、演出次数、断网跳车和诊断记录。
- 保留团队演出、本地协力网络恢复、开演证据和校准功能。
- 协力新增不指定、随机或当前曲目，并采用稳定 PGGBM 数字读取与安全弹窗收尾。
- 启动时清理超过 24 小时的自动日志、截图和诊断信息，保留手动录像与未完成校准证据。
- 使用 RhythmPilot 名称与原创图标，更新和反馈地址指向自己的仓库。

## 上游迁入

- 相同标题、封面、等级与谱面摘要的别名自动消歧。
- 真实生命归零保留失败分类；失败退出使用安全确认顺序。
- 独立公告、随包版本说明、图形更新器及中文路径后台重启。
- 任务期间阻止息屏由定制 MFA 实现，任务结束后释放。
- ADB 端口归属、Native 等待成本过滤和协力成员加载页保护继续默认关闭。

## 安装

首次使用请下载完整包并解压到新目录，双击 `启动 RhythmPilot.cmd`。
更新包仅供已安装 RhythmPilot 的便携环境使用，保留配置与 Profile，谱面独立同步。
完整包与更新包各附 SHA256；固定 Python 3.12、MaaFw 5.10.2、定制 MFA 2.12.0。
