# RhythmPilot 1.5.0 上游迁移评估

RhythmPilot 是基于 MaaBanGDream 的非官方版本，独立仓库为
<https://github.com/lin18846443196-arch/MaaBanGDream>。

## 基线与留存

- 上游原基线：`v1.4.3`，`62f3cd1ddc4ec2733435205d91802f5ee08fdfa0`。
- 本地定制快照：`personal-v1.4.3-snapshot`，`1708e4f`。

  定制 MFA 源码提交为 `a39dcd87ba2e5098ee23072e9a015c5c36f8c8d1`。
- 开发分支：`feature/personal-v1.5.0`。迁移采用分组提交，便于单独审查与回退。

上游 1.4.3→1.4.5 共 8 个提交、41 个变更文件。此数量只计算上游差异；
本地快照另有 135 个变更或新增源码、测试、模板文件。原安装目录独立保留。

发布验证额外发现上游 conda-unpack 在深中文目录中不能访问超过 MAX_PATH 的文件。
已增加扩展路径解压及有边界的文件 API 适配，Windows PowerShell 5.1 首次启动准备通过。

低风险曲库变更先提交；演出保护和协力变更随后提交；发布与品牌变更最后迁移。
当前默认关闭的试验项不会因升级自动开启。上游真机记录属于上游，不能作为此分支验收。

## 本地功能保留

- 挑战演出：识别剩余点数，依次选择能承担的 8/4/2/1 倍；不足最低点数安全结束。
  保留难度、次数、断网跳车及诊断选项，正式演奏接入共享引擎与结算。
- 团队演出：独立入口、准备页与最终封面门禁、按局计数、结算和恢复。
- 协力：本地 ROOT/UID 网络恢复、限制等待、准备送达复核、结果处理保护。
- Native/Legacy：本局开演证据、刷新门禁、首组同步和离线校准。
- 启动清理：只清理自动输出中超过 24 小时的旧信息；保留手动录像、配置、
  Profile、未完成校准证据和仍有近期更新的完整记录。锁定文件和链接跳过。

## 发布与回退边界

1. 完整包：`RhythmPilot-v1.5.0-win-x64.zip`，包含版本目录。
2. 更新包：`RhythmPilot-v1.5.0-win-x64-update.zip`，归档根目录直接包含 `interface.json`，
   排除 Python 运行库归档和 `resource/charts`；分别附 SHA256。
3. 许可证、第三方声明与原作者 Required Notice 随包保留；名称和图标独立。
4. 首次使用自己的版本应解压到新目录，经过验收再迁入自己的配置/Profile；
   不直接覆盖旧安装，也不将个人设备配置或原始录像提交 GitHub。
5. 原安装和本地快照可回退。未来更新保留 `config/profiles/logs/debug/screencap`，
   启动时按上述 24 小时策略清理自动诊断。
6. GitHub 登录由用户稍后完成。未授权登录时仅准备本地源码、发布输入与产物，
   不把本地提交描述成已推送、已发布。

正式 Release 还需此版本的模拟器/游戏验收。至少覆盖挑战点数阈值、各难度、
多局计数、断网跳车能力缺失/恢复、协力结算、启动清理和中文路径更新重启。
尚未验收的候选包只能标注为预发布。
